# Handwritten Digit Recognition

## Project Overview
This project uses a Neural Network to recognize handwritten digits
from 0 to 9 using the MNIST dataset.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The MNIST dataset contains 60,000 training images and 10,000 test images.
Each image is a grayscale image of size 28 x 28 pixels.

## Model Architecture
- Flatten layer
- Dense layer with 128 neurons and ReLU activation
- Dropout layer
- Output layer with 10 neurons and Softmax activation

## Results
- Training epochs: 5
- Test accuracy: 97.58%

## Output Files
- accuracy_plot.png
- confusion_matrix.png
- sample_predictions.png
- classification_report.txt

## How to Run
1. Install the required libraries.
2. Run the following command:

   python main.py
